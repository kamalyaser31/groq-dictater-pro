# Groq Dictater Pro

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-0078D6.svg)](https://www.microsoft.com/windows/)
[![GUI](https://img.shields.io/badge/GUI-wxPython-brightgreen.svg)](https://www.wxpython.org/)
[![Accessibility](https://img.shields.io/badge/Accessibility-WCAG%202.1%20AA%20%7C%20NVDA-success.svg)](#إمكان-الوصول)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

تطبيق إملاء صوتي خفيف وفائق السرعة لنظام Windows، يلتقط الصوت من الميكروفون بضغطة زر أو اختصار عالمي، ويرسله سحابياً إلى خدمة Groq لتحويل الكلام إلى نص بدقة عالية عبر نماذج Whisper السحابية، ثم يضع النص المنسوخ في الحافظة مباشرة مع خيار لصقه التلقائي في النافذة النشطة.

صُمم التطبيق ليعمل دون الحاجة إلى عتاد خاص (كبطاقات GPU المتطورة) أو تنزيل نماذج ثقيلة محلياً، وبُني بواجهة `wxPython` قياسية تراعي أرفع معايير الوصولية للمكفوفين وضعاف البصر ومستخدمي قارئات الشاشة (وعلى رأسها NVDA).

---

## المزايا الرئيسة

- **السرعة العالية:** تحويل فوري للكلام عبر خوادم Groq السحابية الفائقة باستخدام طراز `whisper-large-v3-turbo` افتراضياً.
- **اختصار عام قابل للتخصيص:** بدء التسجيل وإيقافه بضغطة زر من داخل أي تطبيق؛ واختصاره الافتراضي `F8`.
- **دعم متعدد اللغات:** دعم العربية والإنجليزية والألمانية والفرنسية والإسبانية.
- **تكامل سلس مع الحافظة:** وضع النص فوراً في الحافظة مع خيار الإلصاق التلقائي بـ `Ctrl+V`.
- **موجّه ابتدائي مخصص (Prompt):** إمكان إدخال مصطلحات وسياق أولي لتحسين كتابة الأسماء والمفردات التخصصية والإسلامية.
- **حماية وتشفير المفاتيح:** تشفير مفتاح API على القرص بحماية Windows DPAPI للمستخدم الحالي، مع دعم القراءة المباشرة من متغير البيئة `GROQ_API_KEY`.
- **أمان تدفق الصوت:** حظر تجاوز سقف 20 ميجابايت من صوت PCM وإيقاف التسجيل تلقائياً صيانةً لموارد النظام ومنعاً لرفض الخادم.
- **وصولية شاملة:** توافق تام مع قارئ الشاشة NVDA، وأسماء صريحة لعناصر التحكم، وترتيب تنقل دقيق بلوحة المفاتيح، وتحديث ديناميكي لحالة زر التسجيل ("بدء الإملاء" / "إيقاف الإملاء") دون الاعتماد على اللون بمفرده.

## متطلبات التشغيل

- **نظام التشغيل:** Windows 10 أو Windows 11 (64-bit).
- **بيئة بايثون:** Python 3.10 أو أحدث.
- **العتاد:** ميكروفون سليم ومضبوط كجهاز إدخال افتراضي.
- **الاتصال:** اتصال فعّال بالشابكة (الإنترنت).
- **المفتاح:** مفتاح حساب مجاني أو مدفوع من [Groq Console](https://console.groq.com/).

## التشغيل والاستعمال

شغّل التطبيق بالأمر:

```powershell
python gui.py
```

### خطوات الاستخدام لأول مرة:
1. اضغط على زر **«الإعدادات ومفتاح الـ API»** داخل النافذة.
2. أدخل مفتاح Groq API الخاص بك (يبدأ عادة بـ `gsk_...`)، واختر اللغة والنموذج المطلوب.
3. اضغط زر **«حفظ الإعدادات»**.
4. اضغط الاختصار `F8` لبدء التسجيل (ستسمع نغمة تنبيه صوتية ويتحول الزر إلى "إيقاف الإملاء").
5. تكلّم بوضوح، ثم اضغط `F8` مرة أخرى لإنهاء التسجيل وإرسال الصوت.
6. يُنسخ النص الناتج فوراً إلى الحافظة، ويُدوّن في سجل نصوص الجلسة.

> [!TIP]
> يمكنك تشغيل التطبيق دون كتابة المفتاح في نافذة الإعدادات بتعيينه كمتغير بيئة مؤقت:
> ```powershell
> $env:GROQ_API_KEY="gsk_ضع_مفتاحك_هنا"
> python gui.py
> ```

يُنشئ التطبيق ملف التهيئة `config.json` بجانب البرنامج عند أول حفظ. ويتوفر في المستودع ملف مرجعي نموذجي [config.example.json](config.example.json).

| **مفتاح API** | فارغ | يُشفّر محلياً بواسطة Windows DPAPI |
| **رابط الخدمة** | `https://api.groq.com/openai/v1/audio/transcriptions` | نقطة نهاية واجهة برمجة Groq |

## الأمان والخصوصية

- **التشفير المحلي:** يُشفّر مفتاح API بواسطة تقنية Windows DPAPI (`win32crypt.CryptProtectData`) قبل كتابته في `config.json`، بحيث لا يمكن فك تشفيره إلا تحت حساب المستخدم الحالي نفسه على الجهاز.
- **نظافة السجلات:** لا تُسجّل نصوص الإملاء الصوتي أو بيانات التفريغ في ملفات السجل (`app.log`) صيانةً لسرية حديث المستخدم.
- **حجب تفاصيل الأخطاء الحساسة:** لا تُعرض استجابات الخادم الخام المتضمنة تفاصيل تشخيصية خاصة للمستخدم عند وقوع أخطاء الاتصال.
- **المعالجة في الذاكرة:** يُحوّل الصوت الملتقط إلى تنسيق WAV داخل الذاكرة العشوائية (`io.BytesIO`) ويُرفع مباشرة دون كتابة ملفات صوتية مؤقتة على القرص.

## إمكان الوصول (Screen Readers & Accessibility)

- متوافق تماماً مع قارئات الشاشة الحديثة، لا سيما **NVDA**.
- عناصر واجهة مستخدم قياسية (Native Windows Controls) عبر `wxPython`.
- وضوح تام في أسماء الحقول ومسمياتها الدلالية عبر `SetName` و `StaticText`.
- ترتيب منطقي صارم للتنقل بمفتاح الجدولة (`Tab Order`).
- تحديث دلالي لحالة الأزرار ("بدء الإملاء" / "إيقاف الإملاء") حتى لا يعتمد إدراك الحالة على اللون بمفرده، التزاماً بمعايير WCAG 2.1 AA.

## بناء الملف التنفيذي المستقل (EXE Build)

يمكن تحويل التطبيق إلى ملف تنفيذي مفرد لا يحتاج إلى تثبيت بايثون بواسطة `PyInstaller`:

```powershell
python -m PyInstaller --noconfirm --clean GroqDictaterPro.spec
```

يظهر الملف التنفيذي الناتج في المجلد `dist\GroqDictaterPro.exe`. لاحظ أن ملف الإعدادات `config.json` لا يُدمج داخل الملف التنفيذي، بل يُنشئه البرنامج تلقائياً بجانبه عند الاستخدام.
