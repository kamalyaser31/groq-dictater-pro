# Groq Dictater Pro

تطبيق إملاء صوتي خفيف لنظام Windows، يسجّل الكلام من الميكروفون ويرسله إلى خدمة Groq لتحويله إلى نص، ثم يضع النص المنسوخ في الحافظة، مع إمكان لصقه تلقائياً في النافذة النشطة.

بُني التطبيق بواجهة `wxPython` وعناصر Windows القياسية، وعُني بتوافق قارئات الشاشة، ولا سيما NVDA. ولا يحتاج إلى تنزيل نماذج محلية أو تثبيت CUDA أو PyTorch.

## المزايا

- بدء التسجيل وإيقافه باختصار عام قابل للتغيير؛ واختصاره الافتراضي `F8`.
- النسخ السحابي السريع عبر Groq، باستعمال `whisper-large-v3-turbo` افتراضياً.
- دعم العربية والإنجليزية والألمانية والفرنسية والإسبانية.
- نسخ النص إلى الحافظة، مع خيار اللصق التلقائي بـ`Ctrl+V`.
- موجه ابتدائي قابل للتخصيص لتحسين الأسماء والمصطلحات وأسلوب الكتابة.
- حفظ مفتاح API مشفراً بحماية Windows DPAPI الخاصة بالمستخدم الحالي.
- إيقاف التسجيل تلقائياً عند 20 MiB من صوت PCM، اتقاءً لتجاوز حد رفع الملفات.
- واجهة محلية بسيطة وسريعة، لا تحفظ النصوص المُملاة في ملفات السجل.

## المتطلبات

- Windows 10 أو Windows 11.
- Python 3.10 أو أحدث.
- ميكروفون صالح للعمل.
- اتصال بالشابكة.
- مفتاح Groq API.

## التثبيت

افتح PowerShell داخل مجلد المشروع، ثم أنشئ بيئة وهمية وثبّت التبعيات:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## التشغيل

شغّل التطبيق بهذا الأمر:

```powershell
python gui.py
```

ثم اتبع الآتي:

1. افتح «الإعدادات ومفتاح API».
2. أدخل مفتاح Groq، واختر اللغة والنموذج وما يلزم من الخيارات.
3. اضغط `F8` لبدء التسجيل.
4. اضغط `F8` مرة أخرى لإيقافه وإرسال الصوت إلى Groq.
5. يُنسخ النص إلى الحافظة، ويظهر في سجل الجلسة داخل النافذة.

يمكن ترك حقل المفتاح فارغاً وتعيينه في متغير البيئة بدلاً من حفظه:

```powershell
$env:GROQ_API_KEY="ضع_مفتاحك_هنا"
python gui.py
```

| الخيار | القيمة الافتراضية | البيان |

| أصوات التنبيه | مفعلة | تنبه إلى بدء التسجيل وإيقافه ونجاح النسخ |
| البقاء في المقدمة | معطل | يبقي نافذة التطبيق فوق النوافذ الأخرى |
| الموجه الابتدائي | موجه عربي | يعين النموذج على ضبط السياق والمصطلحات |

## الخصوصية والأمان

- يُرسل الصوت إلى Groq ليُنسخ سحابياً؛ فالتطبيق ليس أداة نسخ محلية ولا يعمل دون اتصال.
- لا تُكتب النصوص المنسوخة في ملف السجل؛ وإنما تبقى ظاهرة في سجل الجلسة داخل الواجهة.
- تُحفظ الإعدادات في `config.json` بجانب ملفات التطبيق.
- يُحفظ مفتاح API مشفراً للمستخدم الحالي بواسطة Windows DPAPI، ولا يُكتب نصاً صريحاً في ملف الضبط.
- يبقى استعمال متغير البيئة `GROQ_API_KEY` أنسب لمن لا يريد حفظ المفتاح في ملف الضبط.
- اللصق التلقائي يرسل النص إلى النافذة النشطة؛ فتحقق من موضع المؤشر قبل تفعيله.

تستعمل الواجهة عناصر Windows القياسية، ولحقولها أسماء وصول صريحة، وترتيب التنقل فيها بلوحة المفاتيح منطقي. كما تجمع رسائل الحالة بين النص واللون، فلا يتوقف فهمها على اللون وحده.

## بنية المشروع

| الملف | مهمته |
| --- | --- |
| `gui.py` | الواجهة، والاختصار العام، والحافظة، وإدارة تفاعل المستخدم |
| `audio_engine.py` | التقاط الصوت، وآلة الحالات، وإنشاء WAV، والاتصال بخدمة Groq |
| `config.py` | التهيئة، والتحقق من الإعدادات، وتشفير المفتاح، والسجل |
| `run_tests.py` | اختبارات الانحدار المستقلة |
| `requirements.txt` | التبعيات المثبتة الإصدارات |

## الاختبار والتحقق

شغّل فحوص الانحدار بهذا الأمر:

```powershell
python run_tests.py
```

تغطي الاختبارات تشفير مفتاح API، وحد التسجيل، وحجب جسم خطأ الخادم، والإغلاق أثناء النسخ، ومنع تعارض الاختصار مع نافذة الإعدادات، وإهمال نداءات الواجهة المؤجلة بعد الإغلاق.

وفحوص الجودة المعتمدة للمشروع هي:

```powershell
python -m flake8 gui.py audio_engine.py config.py run_tests.py
python -m black --check --line-length 79 gui.py audio_engine.py config.py run_tests.py
```

## بناء ملف EXE

يتطلب البناء `PyInstaller`. أنشئ الملف التنفيذي الواحد بالأمر:

```powershell
python -m PyInstaller --noconfirm --clean GroqDictaterPro.spec
```

يظهر الناتج في `dist\GroqDictaterPro.exe`. لا يُضم `config.json` إلى
الملف التنفيذي؛ ينشئ التطبيق إعداداته بجانب EXE عند حفظها.
